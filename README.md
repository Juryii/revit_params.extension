# revit_params.extension
pyrevit extension для добавления параметров к элементам модели

## Расчёт закупки креплений

Params → Крепления → Расчёт закупки. Кнопка читает все отдельные детали
семейств РП в текущем проекте, включая общие вложенные детали. Связанные
модели не учитываются. Модель и спецификации не изменяются.

Длины закупаемых шпилек и траверс вводятся отдельно в миллиметрах, по
умолчанию 3000. Потеря на рез по умолчанию 0 мм: задайте её для вашего
инструмента. На каждый отрезок резервируется один рез; целая заготовка
используется без реза. Припуски на одну шпильку и на одну траверсу вводятся
отдельно, по умолчанию 0 мм. Для раскроя к каждой длине из модели один раз
добавляется припуск соответствующего вида: 920 + 50 = 970 мм. Припуск 50 мм
означает 50 мм на всю деталь, а не на каждый конец. Длины в модели и основной
спецификации не меняются. Карта раскроя показывает длины уже с припуском;
потеря на рез учитывается дополнительно. Отрезки, которые стали длиннее
заготовки после добавления припуска, показываются как неучтённые.

В отчёте pyRevit — количество заготовок в штуках, расход, потери на рез,
остатки и повторяемые схемы раскроя. Заготовки одного наименования,
обозначения и изготовителя раскраиваются совместно для разных систем.
Траверсы и шпильки всегда разделены. Шпильки М8/М10 круглых подвесов
и выборные шпильки прямоугольных поддерживаются вместе.

Отрезки длиннее заготовки или не помещающиеся с учётом реза выводятся
отдельно с ссылками на элементы и **не включаются в заказ**. Автоматическое
сращивание не предполагается. Нулевые и отсутствующие длины также отмечаются.

Алгоритм сначала строит допустимый раскрой best-fit decreasing, затем
ищет доказанный минимум с ограничением времени и числа шагов. Галочка
«Настроить расширенный поиск» включает пользовательские общие лимиты
для всех профилей и резьб: по умолчанию 300 секунд и 10 000 000 шагов.
Без галочки общие лимиты — 0,4 секунды и 30 000 шагов. Поиск останавливается
по первому лимиту; доказанный минимум завершает поиск группы раньше.
Лимит на число отрезков отсутствует, перебор не использует рекурсию.
Индикатор показывает время и шаги, «Отмена» доступна во время перебора.
Отменённый расчёт не выдаёт готовый заказ. При исчерпании лимита отчёт
сохраняет допустимый раскрой для всех групп и указывает причину остановки.
Сбор данных, первоначальный подбор и вывод отчёта занимают дополнительное
время. Если минимум не доказан, отчёт явно помечает результат как подбор.
Все расчёты округляют требуемые длины вверх до 0,001 мм.
Запасы склада и применение остатков из предыдущих заказов не учитываются.
Число в заказе относится только к прошедшим проверку отрезкам.

Файлы кнопки: `Params.tab/Крепления.panel/Расчет закупки.pushbutton`;
алгоритм: `lib/support_cutting.py`. Для удаления кнопки удалите её папку
и перезагрузите pyRevit. Проверки: `python -m unittest discover -s tests`.

## Разделение прямоугольных воздуховодов

Params → Воздуховоды → Разбить по 1250. Если есть выделение, кнопка работает
только с ним. Без выделения предлагает выбрать элементы, текущий вид или
весь проект. Связанные модели исключены. Перед применением — одно короткое
подтверждение с числом воздуховодов, разрезов и пропусков. После успешного
запуска — отчет без итогового алерта; причины пропуска приведены в отчете.

Обрабатываются прямолинейные жесткие прямоугольные воздуховоды без
заполненного производителя у экземпляра **и** типа: стандартный параметр
«Изготовитель», ADSK_Завод-изготовитель, ADSK_Изготовитель, «Производитель»
и Manufacturer. Любой непустой текст считается заполненным производителем.
Группы, закрепленные элементы, круглые воздуховоды и заполнители пропускаются.

1750 мм → 1250 + 500; 4470 мм → 1250 + 1250 + 1250 + 720.
Участки до 1250 мм остаются целыми; повторный запуск не создает новых разрезов.
Отсчет идет от начала осевой линии Revit, независимо от направления потока.
Если остаток меньше допустимой длины Revit, исходный участок целиком
пропускается с пояснением. Погрешность вычислений до 0,01 мм допускается.

Новые торцы соединяются напрямую, без вставки муфт или фланцевых семейств,
чтобы сохранить заданные длины. После завершения транзакции проверяются
система, тип, сечение, изоляция/облицовка, исходные подключения и длины.
Ошибка или отмена откатывает **весь запуск**. Успешный запуск отменяется
одним Ctrl+Z. Файл проекта автоматически не сохраняется.

Проверено пробным запуском с откатом в Revit 2025 на реальном проекте:
19 воздуховодов, 31 разрез; сохранены системы, изоляция и соединения.
Алгоритм: `lib/duct_split.py`; кнопка:
`Params.tab/Воздуховоды.panel/Разбить по 1250.pushbutton`.
Для удаления удалите эту папку кнопки и перезагрузите pyRevit.

## Закупка прямоугольных воздуховодов, шин и уголков

Params → Воздуховоды → Закупка воздуховодов. Одно окно настроек, затем отчет,
без итогового алерта. Модель и спецификации не изменяются. Область —
выделенные элементы, текущий вид или весь проект; связанные модели исключены.
При наличии выделения оно выбрано по умолчанию, иначе — весь проект.
В начале отчета — общая закупка заготовок воздуховодов 1250 мм:
сколько купить, сколько установить целыми и сколько заготовок пустить
на раскрой. Количество коротких деталей, полученных из этих заготовок
для монтажа, показано отдельно: одна заготовка может дать несколько деталей.
Далее — разбивка по сечениям/типам/материалам, остатки и закупка шин с уголками.
«Купить» = «целыми в монтаж» + «заготовок в раскрой».
«Участков в монтаж» = «целыми» + «коротких отрезков».
Внешний складской запас не вычитается, процент запаса не добавляется.
Подробные карты раскроя скрыты по умолчанию и включаются галочкой в окне.
Рассчитываются только прямые жесткие прямоугольные воздуховоды без
производителя у экземпляра и типа, по тем же параметрам, что у кнопки разделения.
Фасонные детали и оборудование не включены.

Размер шины определяется по большей стороне сечения: до 1000 мм
включительно — 20, больше — 30, по правилу пользователя.
Перед каждым расчетом можно выбрать уголок УГФ-0 (65×18×3) или
УГФ-1 (95×18×3) для шины 20; для шины 30 используется УГФ-2 (105×27×3),
по предоставленному каталогу. Размеры в миллиметрах.

Заводские фланцы и уголки целого отрезка 1250 мм уже входят в поставку.
Количество новых фланцев нельзя вывести только из количества соединений
в модели: нужен раскрой заготовок по одинаковым сечениям, материалу и шине.
У короткого отрезка из конца заготовки один новый фланец, из середины — два.
Два отрезка 500 мм можно взять с противоположных концов одной заготовки:
два новых фланца суммарно, восемь уголков. Остаток 250 мм будет без
заводских фланцев. Если его использовать, на нем нужны два новых фланца.

В режиме **нового раскроя** одинаковые сечения одного типа, толщины,
материала и покрытия объединяются между системами. Заготовки разных групп
не смешиваются. В карте каждая деталь привязана к ID воздуховода; показаны
0/1/2 сохраненных заводских торца и новые фланцы. При нескольких деталях
первая идет от одного заводского края, последняя — от противоположного,
остальные — между ними; остаток располагается перед последней деталью.
У одиночной короткой детали один заводской торец, у оставшейся части
заготовки — второй. У цельной детали 1250 мм оба торца заводские.

Например, 1250 + 500 мм требуют один дополнительный фланец и 4 уголка;
500 + 500 из одной заготовки — 2 фланца и 8 уголков; 400 + 400 + 400 —
4 фланца и 16 уголков: у средней детали два новых торца.
Подбор сокращает количество заготовок по принятому резерву на рез.
Минимум заготовок отмечается только при доказанном результате ограниченного
поиска (общие лимиты 2 секунды / 200 000 шагов). Минимальная стоимость
комплекта воздуховодов и фланцев, а также минимум числа фланцев не обещаются.

Для **уже нарезанных деталей** доступны два режима: один заводской торец
у каждого короткого отрезка либо оба торца без заводского фланца.
Цельные 1250 мм в обоих режимах остаются с двумя заводскими фланцами.
При смешанном происхождении выполняйте расчеты соответствующих выделений
отдельно. Геометрия модели не определяет происхождение торцов автоматически.
В этих двух режимах показываются монтажные количества, шины и уголки;
новая закупка заготовок воздуховодов не определяется и отмечается прочерком.
Для полного заказа воздуховодов выбирайте режим новой закупки/раскроя 1250 мм.

На каждый новый фланец — 4 уголка и по две шины вдоль каждой стороны.
Длина одной шины = сторона сечения − пользовательский вычет для шины 20/30.
Вычет относится ко всей шине, а не к каждому концу; например, при стороне
500 мм и вычете 20 мм длина реза 480 мм. При вычете 0 метраж идет по периметру.
Точный вычет задается по посадке выбранного уголка, автоматически из его
габаритной длины он не выводится. Вычеты 0 по умолчанию дают предварительные
длины по сторонам воздуховода.

Длины покупной шинорейки 20/30 вводятся отдельно, по умолчанию 3000 мм;
это стартовые значения настройки, их нужно сопоставить с поставкой.
Шины 20 и 30 раскраиваются отдельно, совместно для разных сечений и систем.
Отчет содержит метраж, количество покупных заготовок, уголки и карту реза.
Заводские шины и уголки в дополнительных количествах не учитываются.

Для воздуховодов и шин задаются отдельные потери на рез, по умолчанию 0.
На каждую короткую деталь резервируется один рез, на целую заготовку — ноль.
Это консервативная схема: общий рез между соседними деталями не оптимизируется.
Внешние складские остатки и процент запаса не учитываются.
Воздуховоды длиннее 1250 мм сначала нужно разделить. Такие элементы,
невмещающиеся шины и отрезки с потерей на рез перечислены отдельно.
При исключениях отчет явно помечается как **неполный**, количества относятся
только к учтенным деталям. Отмена расчета не создает отчет закупки.

Проверено в Revit 2025: 82 подходящих участка в 19 группах, новый раскрой
без потерь и вычетов — 59 новых фланцев, 236 уголков, 89,4 м шины 20.
Закупка воздуховодов — 64 заготовки по 1250 мм: 31 в монтаж целиком,
33 в раскрой для получения 51 короткой детали. Проверен баланс
покупной длины, монтажной длины, остатка и потерь на рез.
Проверены три режима учета торцов, выбор УГФ-1 и формирование отчетов.
Алгоритм: `lib/duct_flanges.py`; кнопка:
`Params.tab/Воздуховоды.panel/Закупка воздуховодов.pushbutton`.
Для удаления удалите папку кнопки и перезагрузите pyRevit.
Проверки всех алгоритмов: `python -m unittest discover -s tests`.

## Иконки

Иконки кнопок имеют светлый и тёмный варианты, размер PNG — 32×32.
Рядом сохранены редактируемые SVG. Для повторной генерации с Pillow:
`python tools/generate_icons.py`.

Локальная папка `семейства` и временная папка `tmp` исключены из Git.
